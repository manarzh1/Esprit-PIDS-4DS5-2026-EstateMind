💡 Comment ça fonctionne ?

Ce modèle analyse 10 ans de données trimestrielles sur les prix immobiliers en Tunisie et prédit leur évolution future.

  • 📍 Gouvernorat : la région que vous voulez analyser
  • 🏷️ Variable : le type de bien (appartement, maison…)
  • 📅 Horizon : combien de trimestres dans le futur
  • ⚙️ Ordres : laissez les valeurs par défaut si vous n'êtes pas sûr
Le graphique montrera la tendance passée et une prévision avec une fourchette de confiance à 95%.

💡 Comment ça fonctionne ?

Un modèle d'intelligence artificielle entraîné sur plus de 10 000 annonces tunisiennes calcule le prix juste de votre bien.

  • 🏙️ Ville : où se situe le bien
  • 📐 Surface & pièces : les caractéristiques physiques
  • ⭐ Équipements : 0 = aucun équipement, 10 = tout inclus (clim, parking…)
  • 💰 Budget : optionnel, pour savoir si le prix est dans votre fourchette
Vous obtiendrez un prix estimé, une fourchette de confiance et une comparaison avec le marché local.
